# Provenly Employment VC Platform - Documentation

## Overview

This directory contains comprehensive documentation for the Provenly Employment VC Platform, a microservices-based Verifiable Credentials system built with Hyperledger Besu, EBSI APIs, walt.id, and modern cloud-native technologies.

## Key Features

- 🔐 **EBSI Integration** - Full integration with European Blockchain Services Infrastructure
- 🏗️ **Microservices Architecture** - Scalable, maintainable service-oriented design
- 🔒 **Selective Disclosure** - Privacy-preserving credential sharing
- 📜 **JSON-LD Support** - Semantic interoperability with linked data
- ⛓️ **Hyperledger Besu** - Enterprise-grade blockchain for DID anchoring
- 🎯 **Walt.id Integration** - Professional VC/VP processing capabilities
- 📊 **Comprehensive Monitoring** - Full observability with Prometheus, Grafana, and Jaeger
- 🚀 **Cloud Native** - Kubernetes-ready with CI/CD pipelines
