## 🚀 **Quick Start Instructions**

### **Step 1: Navigate to Project**
```bash
cd frontend-apps/holder-wallet/mobile-new
```

### **Step 2: Install Dependencies**
```bash
# Install all packages (should work without conflicts now)
npm install --legacy-peer-deps
```

### **Step 3: iOS Setup (macOS only)**
```bash
# You'll need to initialize the iOS project first
npx react-native run-ios --simulator="iPhone 15"
# This will create the ios/ directory and install pods
```

### **Step 4: Start Development**
```bash
# Start Metro bundler
npm start

# In another terminal, run the app
npm run ios    # or npm run android
```
